# Task 13 - NumPy Data Filtering

## AI & ML Internship – Task 13

### Objective

To use NumPy conditions to identify and filter numerical values that are above, below, or equal to a specified threshold.

### Description

This project demonstrates numerical data filtering using NumPy in Python. A NumPy array is created, and Boolean conditions are applied to extract values that satisfy specific criteria.

### Technologies Used

* Python
* NumPy
* Jupyter Notebook

### Features

* Creates a NumPy array containing numerical values.
* Filters values greater than 50.
* Filters values less than 50.
* Identifies values equal to 50.
* Filters values greater than or equal to 75.
* Extracts values within a specified range.
* Demonstrates Boolean indexing.

### Concepts Learned

* NumPy arrays
* Boolean conditions
* Boolean indexing
* Numerical data filtering
* Comparison operators
* Logical operators

### How to Run

1. Install Python and NumPy.
2. Clone or download this repository.
3. Open the Python file or Jupyter Notebook.
4. Run the code to view the filtered results.
